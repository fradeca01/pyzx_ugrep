## ⚠️ This is a thesis fork ⚠️

This fork of [PyZX]("https://github.com/zxcalc/pyzx") contains some additions to the Python library, as well as benchmarks and results from my master's thesis. All files are **untouched** from the original repo apart from:
- Some additions inside the pyzx package source code.
- File and folders specific to my thesis work, inside `thesis/`.

## Additions

The main addition done are the following:
- Added the `graph_state` subpackage, which provides methods to create and work with `graph states` from pyzx graphs. 

- Added the `uinversal_representation` subpackage, which provides methods to transform a Clifford ZX diagram to its universal representation.
